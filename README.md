# Snip —— 约 65KB 的极简截图工具（V1.10 双击动作可配置版）

一个绿色免安装、单文件（约 65KB）的 Windows 截图工具。**双击即截图，截完可直接标注**，纯鼠标操作。

![icon](图标预览.png)

## ✂️ 特性
- 双击 exe **直接进入截图状态**，无需设置
- 按住左键拖选 → 松开即完成截图
- 截图后**就地标注**：画笔 / **直线** / **波浪线** / 矩形 / 椭圆 / 箭头 / 马赛克 / **文字**（数字键 1~8 快速切换）
- 标注颜色：红 / 绿 / 蓝 / 黑 / 白（按 R / G / B / K / W 键切换），粗细可调（细 2px / 粗 6px）
- 🆕 **文字标注**：选「文字」后**按住左键拖拉出文本框**（有虚线预览），松手输入文字；**输入框为多行、与拖动框同宽同高**，**文字按框大小自动换行缩放**，颜色跟随标注色
- 🆕 **拖动/缩放/编辑（V1.10）**：鼠标移到文字框**四边**→ 移动光标（拖动移动）；移到**四角**→ 斜向箭头（拖动缩放），文字自动重排；**双击文字 = 重新编辑**，**双击空白 = 完成截图**；输入框为近似透明底色、无边框、无滚动条；**截图选区**也支持边=移动、角=缩放
- **双击左键 = 按设置的动作完成截图**（V1.10 新增：设置里可勾选「复制到剪贴板」「保存到截图保存路径」，可同时勾选；默认只复制；两个都不勾时按复制执行）；单击右键 = 菜单（标注 / 复制 / 保存到默认位置 / 另存为… / 取消）；按 Enter 直接保存
- 🆕 **全屏截图（V1.5，原“静默截图”）**：按 `Alt+Shift+X`（可自定义）→ **不弹界面、无需鼠标**，自动截全屏并**保存到所选文件夹**（默认桌面，可在「设置…」里改），文件名 `yyyyMMddHHmmss.jpg`
- Esc 分层：文字输入中 = 取消这次输入；文字工具待命 = 退出文字工具（回画笔）；其余情况 = 撤销上一笔，无标注时退出截图
- 常驻托盘：悬停提示当前快捷键（一行短句，随自定义实时更新）；「设置…」四个编号区块（1 启动设置 / 2 快捷键设置 / 3 保存路径设置 / 4 版本信息），**改动即时生效**、Esc 不关窗
- 🆕 **双击必有反应（V1.10）**：程序未运行时双击 = 启动并直接框选；已在运行时双击 = 该次进程自己完成一次框选截图后退出；诊断日志见 exe 同目录 `Snip.log`
- 🆕 **版本信息（V1.10）**：托盘菜单已移除「关于 Snip…」，版本信息改到**设置窗口最后一行**（形如 `Snip V1.10 ｜ .NET Framework 4.8`）；exe 属性里文件版本为 1.10.0.0
- 🆕 **配置文件改用单个 `Snip.ini`（V1.10）**：与 exe 同目录，记事本可直接编辑，分 `[Hotkey]` / `[General]` / `[Save]` / `[Anno]` 四节；旧的 `Snip.config`、`SnipSaveDir.config`、`SnipAnno.config` 不再读取（可手动删除，升级后请重新设置一次）
- 无广告、无弹窗、无捆绑、不联网、不上传任何数据
- 支持多显示器、高分屏(DPI)像素精准
- Win10 / Win11 免安装直接运行（基于系统自带 .NET Framework）

## 🖱️ 使用
1. 双击 `Snip.exe`，拖选要截取的区域，松开完成
2. 如需标注：按住左键画出画笔 / 矩形 / 椭圆 / 箭头 / 马赛克；选「文字」后拖拉出文本框即可输入文字
3. 双击左键按设置的动作完成（默认复制到剪贴板；勾选「保存到截图保存路径」后同时存成 `yyyyMMddHHmmss.jpg`），或单击右键另存为
4. 想不弹界面、一键存全屏：按 `Alt+Shift+X`（生成 `yyyyMMddHHmmss.jpg`）；两个快捷键、截图保存路径、双击动作都可在托盘「设置…」里自定义（快捷键点方框后按键盘即可修改）
