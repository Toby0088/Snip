# Snip —— 26KB 的极简截图工具

一个绿色免安装、只有 **26KB** 的 Windows 截图工具。**双击即截图，纯鼠标操作**。

![icon](图标预览.png)

## ✂️ 特性
- 双击 exe **直接进入截图状态**，无需设置
- 按住左键拖选 → 松开即完成
- **双击左键 = 复制**；**单击右键 = 另存为**
- 常驻托盘，全局快捷键（默认 Alt+X，托盘菜单可自定义）一键截图
- 无广告、无弹窗、无捆绑、不联网、不上传任何数据
- 支持多显示器、高分屏(DPI)像素精准
- Win10 / Win11 免安装直接运行（基于系统自带 .NET Framework）

## 📥 下载
- [Releases 页面](https://github.com/toby0088/Snip/releases) 下载 `Snip.exe`（26KB）

## 🖱️ 使用
1. 双击 `Snip.exe`
2. 拖选区域，松开完成
3. 双击左键复制到剪贴板 / 单击右键保存
