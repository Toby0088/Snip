# Snip —— 约 53KB 的极简截图工具（V1.6 标注版）

一个绿色免安装、单文件（约 53KB）的 Windows 截图工具。**双击即截图，截完可直接标注**，纯鼠标操作。

![icon](图标预览.png)

## ✂️ 特性
- 双击 exe **直接进入截图状态**，无需设置
- 按住左键拖选 → 松开即完成截图
- 截图后**就地标注**：画笔 / 矩形 / 椭圆 / 箭头 / 马赛克（数字键 1~5 快速切换）
- 标注颜色：红 / 绿 / 蓝（按 R / G / B 键切换），粗细可调（细 2px / 粗 6px）
- **双击左键 = 完成并复制到剪贴板**；单击右键 = 菜单（保存 / 另存为 / 取消…）；按 Enter 直接保存
- 🆕 **静默截图（V1.5）**：按 `Alt+Shift+X`（可自定义）→ **不弹界面、无需鼠标**，自动截全屏并**保存到所选文件夹**（默认桌面，可在「设置…」里改），文件名 `yyyyMMddHHmmss.jpg`
- Esc：有标注时撤销上一笔，无标注时退出截图
- 常驻托盘：悬停提示当前快捷键；全局快捷键（默认 Alt+X）可在托盘「设置…」自定义；通知气泡可关闭
- 无广告、无弹窗、无捆绑、不联网、不上传任何数据
- 支持多显示器、高分屏(DPI)像素精准
- Win10 / Win11 免安装直接运行（基于系统自带 .NET Framework）

## 🖱️ 使用
1. 双击 `Snip.exe`，拖选要截取的区域，松开完成
2. 如需标注：按住左键画出画笔 / 矩形 / 椭圆 / 箭头 / 马赛克
3. 双击左键复制到剪贴板，或单击右键另存为
4. 想不弹界面、一键存全屏：按 `Alt+Shift+X`（生成 `yyyyMMddHHmmss.jpg`）；截图/静默快捷键、静默保存路径与通知开关都可在托盘「设置…」里自定义
