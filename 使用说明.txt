Snip 截图工具使用说明（V1.5）
=====================

这是一个类似 Everything 的绿色轻量截图软件：单个 exe，无需安装。

【启动即截图】
1. 双击 “Snip.exe”——不会弹主窗口，直接进入截图状态！
2. 按住鼠标左键拖动，框选要截取的区域，松开鼠标即完成截图。
3. 框选松开后，光标立即变成画笔，可直接在截图上标注：
     标注形状：右键菜单「标注形状」选 画笔/矩形/椭圆/箭头/马赛克（或按数字键 1~5）
     标注颜色：右键菜单「标注颜色」或按 R / G / B 键切换红/绿/蓝（笔光标颜色同步变化）
     线条粗细：右键菜单「线条粗细」选 细(2px) / 粗(6px)
     标注设置：本次运行内自动保持；重启后恢复默认样式（右键菜单「将当前样式设为默认」可更改默认）
     按住鼠标左键拖动 = 画出所选形状；不想标注直接进行下一步
4. 完成截图：
     双击左键   = 完成截图并复制到剪贴板（最常用）
     单击右键   = 菜单：标注形状 / 标注颜色 / 线条粗细 / 将当前样式设为默认 / 复制到剪贴板 / 保存到默认位置 / 另存为… / 取消截图
     按 Enter   = 直接保存到默认位置
5. Esc 键：有标注时按一次撤销上一笔；无标注时按一次退出截图

【托盘右键菜单（V1.5 起）】
- 开始截图（Alt + X）—— 框选截图
- 静默截图（Alt + Shift + X）—— 自动截全屏并存图，不弹界面
   （括号里显示的是你当前设置的快捷键，改了会实时更新）
- 快捷键与保存设置… —— 打开设置对话框：
     · 修改「开始截图」快捷键 /「静默截图」快捷键（各有一个「修改…」和「默认」按钮）
     · 修改「静默截图保存路径」（默认桌面；「浏览…」可改成任意文件夹，「默认桌面」可还原）
- 意见反馈 —— 打开 GitHub Issues
- 退出

【静默截图（自动保存）】
- 不弹框选界面、不要求鼠标操作，一键自动截全屏并保存成图片文件：
     按静默截图快捷键（默认 Alt + Shift + X，可在设置中修改）
     或托盘右键 → 「静默截图（Alt + Shift + X）」
- 效果：瞬间截取整个屏幕 → 自动保存到【静默截图保存路径】指定的文件夹
     · 默认保存到【桌面】
     · 可在 托盘右键 →「快捷键与保存设置…」→「浏览…」里改成其他文件夹
     · 保存目录配置存在 exe 同目录 SnipSaveDir.config；删除该文件即恢复默认桌面
- 文件名格式：yyyyMMddHHmmss.jpg（例：20260905143025.jpg）
- 保存后弹出托盘气泡提示文件名；截图不会进入剪贴板

【常驻托盘】
- 程序启动后常驻屏幕右下角托盘（彩色剪刀小图标），关掉截图后仍驻留。
- 双击托盘图标 = 立即开始截图。
- 两个全局快捷键默认：Alt + X 框选截图、Alt + Shift + X 静默截图（均可在设置中自定义，也可一键恢复默认）。
- 快捷键配置保存在 exe 同目录 Snip.config，绿色可携带、重启不丢。

【默认保存位置】
- 框选截图（Enter/双击）：C:\Users\你的用户名\Pictures\Screenshots\，文件名 截图_年月日_时分秒.png
- 静默截图：默认桌面（可自定义），文件名 yyyyMMddHHmmss.jpg

【小技巧】
- 想固定在桌面/任务栏：右键 exe → 发送到 → 桌面快捷方式，或“固定到任务栏”。
- 想退出：托盘图标右键 → 退出。

【名字】
- Snip：剪刀“剪”之意，简单易记，一眼认出是截图工具。

【特点】
- 单个文件，约 53 KB，绿色免安装，拷到 U 盘也能用。
- 图标：圆角渐变背景 + 白色剪刀，深浅色任务栏都清晰可见。
- 支持多显示器（框选/静默截图均覆盖所有屏幕）。
- 高分屏(DPI)显示正常，像素不会偏移。
- 基于 Windows 自带 .NET Framework 4.x，Win10/Win11 均可直接运行，无需联网安装任何东西。
