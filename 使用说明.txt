Snip 截图工具使用说明（V1.11）
=====================

这是一个类似 Everything 的绿色轻量截图软件：单个 exe，无需安装。

【启动即截图】
1. 双击 “Snip.exe”——默认不会弹主窗口，直接进入截图状态！
2. 按住鼠标左键拖动，框选要截取的区域，松开鼠标即完成截图。
3. 框选松开后，光标立即变成画笔，可直接在截图上标注：
     标注形状：右键菜单「标注形状」选 画笔/直线/波浪线/矩形/椭圆/箭头/马赛克/文字（或按数字键 1~8）
     标注颜色：右键菜单「标注颜色」或按 R / G / B / K / W 键切换 红/绿/蓝/黑/白（笔光标颜色同步变化）
     线条粗细：右键菜单「线条粗细」选 细(2px) / 粗(6px)
     添加文字：选「文字 (8)」→ 在截图上按住左键拖拉出文本框（显示虚线预览框）→ 松开 → 打字 → 回车确认
              输入框与拖动框同宽同高（多行），可直接输入多行文字；Ctrl + 回车 = 框内换行
              文字会按框的大小自动换行并缩放，颜色跟随当前标注颜色；最终图里只显示文字（无边框）
              单击不拖拉 = 生成默认大小文本框（约 200×44）
              移动/缩放：鼠标移到框的「四边中段」→ 光标变移动样式 → 拖动可整体移动；
                        鼠标移到「四个角」→ 光标变斜向双箭头 → 拖动可调整大小（输入中、已落文字都可调）
                        文字会自动重新换行缩放；输入框为近似透明底色、无边框、无滚动条
              双击编辑：双击已有文字 → 重新进入编辑，改完回车确认；双击空白处 → 完成截图（复制/保存）
              连续添加：文字工具下可继续拖出新文本框；按 Esc 退出文字工具
              选区调整：截图选区的四边 = 移动选区、四角 = 缩放选区（与文本框同一套逻辑）
              确认后工具自动切回画笔，此时双击即可完成并复制；想再加文字请再按 8
     文字模式退出：输入框打开时按 Esc = 取消这次输入；文字工具待命时按 Esc = 退出文字工具（回画笔）；
                  之后按 Esc 才恢复「撤销上一笔 / 无标注时退出截图」
     小提示：在文字工具下直接双击 = 先确认输入框内容，再完成截图并复制
     标注设置：本次运行内自动保持；重启后恢复默认样式（右键菜单「将当前样式设为默认」可更改默认）
     按住鼠标左键拖动 = 画出所选形状；不想标注直接进行下一步
4. 完成截图：
     双击左键   = 按设置的动作完成（默认只复制到剪贴板；V1.10 起可在「设置…」的「3．保存路径设置」里勾选「同时保存到上面的路径」，两个都勾 = 既复制也保存；两个都不勾时按复制执行）
     单击右键   = 菜单：标注形状 / 标注颜色 / 线条粗细 / 将当前样式设为默认 / 另存为… / 取消截图（V1.10 起已移除“复制到剪贴板/保存到默认位置”两项）
     按 Enter   = 直接保存到默认位置
5. Esc 键：有标注时按一次撤销上一笔；无标注时按一次退出截图

【托盘】
- 鼠标悬停在托盘图标上，显示一行短提示：区域 Alt+X ｜ 全屏 Alt+Shift+X。
  （V1.10 起把快捷键压成紧凑写法并缩短文案；改成自定义快捷键后会自动同步）
- 双击托盘图标 = 立即开始截图。

【托盘右键菜单】
- 区域截图（Alt + X）—— 框选截图
- 全屏截图（Alt + Shift + X）—— 自动截全屏并存图，不弹界面
   （括号里显示的是你当前设置的快捷键，改了会实时更新）
- 设置… —— 打开设置对话框（四个编号区块；**所有改动即时生效**，无需点“应用”）：
     1．启动设置 —— ☑ 双击图标 / 启动时直接进入截图（关闭则只在托盘待命，需按快捷键）
     2．快捷键设置 —— 区域截图 / 全屏截图 两行
         双击方框后按键盘组合键即可修改；Esc 取消本次输入；右侧「默认」恢复默认值
     3．保存路径设置 —— 区域截图：☑复制到剪贴板（默认） ☐同时保存到全屏截图路径（yyyyMMddHHmmss.jpg）
         全屏截图：保存路径（默认桌面，可「浏览…」；「默认桌面」还原）
         说明：只有一个保存路径；全屏截图固定使用它，区域截图勾选后使用同一路径与格式
     4．版本信息 —— 一行显示：Snip V1.11 ｜ .NET Framework 4.8（4.0.30319.42000）
         下方为「检查更新」和「跳过此版本」按钮；有新版时更新按钮显示为绿色加粗的「绿点 + 立即更新 V1.11」
     提示：两个快捷键不能相同时会红字提示并自动恢复上一次设置；快捷键被其他程序占用同样会回退
     窗口底部只有「关闭」按钮（V1.10 起 Esc 不再关闭设置窗口）
- （V1.10 起托盘菜单已移除「关于 Snip…」；V1.11 起托盘菜单**不再提供「检查更新」**，检查与更新入口统一放在设置窗口的「4．版本信息」；有新版时托盘图标显示绿点、托盘菜单「设置…」会显示绿点和「有新版本 V1.11」）
- 意见反馈 —— 打开 GitHub Issues
- 退出

【全屏截图（自动保存）】
- 不弹框选界面、不要求鼠标操作，一键自动截全屏并保存成图片文件：
     按全屏截图快捷键（默认 Alt + Shift + X，可在设置中修改）
     或托盘右键 → 「全屏截图（Alt + Shift + X）」
- 效果：瞬间截取整个屏幕 → 自动保存到【截图保存路径】指定的文件夹
     · 默认保存到【桌面】，可在 托盘右键 →「设置…」→「浏览…」改成其他文件夹
     · 保存目录写在 exe 同目录 Snip.ini 的 [Save] Dir（留空 = 桌面）
- 文件名格式：yyyyMMddHHmmss.jpg（例：20260905143025.jpg）
- V1.10 起已取消托盘气泡通知，保存后不再弹出提示；截图不会进入剪贴板（结果请到保存路径查看）

【版本信息】
- 设置窗口（托盘右键 →「设置…」）的「4．版本信息」显示：Snip V1.11 ｜ .NET Framework 4.8（4.0.30319.42000），下方为「检查更新 / 立即更新」。
- 也可右键 exe →「属性」→「详细信息」查看文件版本（1.11.0.0）。

【常驻托盘】
- 程序启动后常驻屏幕右下角托盘（彩色剪刀小图标），关掉截图后仍驻留。
- 两个全局快捷键默认：Alt + X 框选截图、Alt + Shift + X 全屏截图（均可在设置中自定义，也可一键恢复默认）。
- 快捷键与所有选项**统一保存在 exe 同目录 Snip.ini**（V1.10 起），绿色可携带、重启不丢。

【配置文件 Snip.ini】
- 与 exe 同目录，记事本可直接编辑，保存后重启生效：
     [Hotkey]  DragSnip / FullScreen        快捷键，写法如 Alt + X、Ctrl + Alt + A
     [General] Notify / AutoCapture / DoubleClickCopy / DoubleClickSave    开关，1=开 0=关
     [Save]    Dir                          截图保存路径，留空 = 桌面
     [Anno]    Shape / Color / Width / TextSize    标注默认样式（颜色如 #FF0000）
- 注意：V1.10 起改用 Snip.ini；旧的 Snip.config / SnipSaveDir.config / SnipAnno.config 不再读取（可直接删除）。

【默认保存位置】
- 框选截图按 Enter（“保存到默认位置”）：C:\Users\你的用户名\Pictures\Screenshots\，文件名 截图_年月日_时分秒.png（同时复制到剪贴板）
- 双击保存（勾选「同时保存到『全屏截图』的保存路径」后）与全屏截图：写入【截图保存路径】，默认桌面，文件名 yyyyMMddHHmmss.jpg

【小技巧】
- 想固定在桌面/任务栏：右键 exe → 发送到 → 桌面快捷方式，或“固定到任务栏”。
- 想退出：托盘图标右键 → 退出。

【双击打开 & 诊断日志】（V1.10）
- 双击 Snip.exe：若程序未运行 → 启动并直接进入框选截图；若已在运行（托盘驻留）→ **当前这次双击会自己完成一次框选截图**后退出，绝不出现“双击没反应”。
- 若在「1．启动设置」里选择了“双击应用仅打开程序”，该设置只对第一次冷启动生效；程序已运行在托盘时，再次双击 exe 或托盘图标仍会进入截图。
- 诊断日志：exe 同目录 `Snip.log`，记录启动、单实例判定、托盘图标注册、热键注册结果、截图结果与异常；超过 256KB 自动重写。
- 若双击仍无反应：看 `Snip.log` 最后几行；或先在任务管理器结束残留的 `Snip.exe` 再试。

【名字】
- Snip：剪刀“剪”之意，简单易记，一眼认出是截图工具。

【更新检查】（V1.11 新增）
- 程序启动约 3 秒后，静默检查一次是否有新版本（**每天最多一次**）
- 发现新版本时：托盘图标右下角出现**绿色小圆点**；托盘菜单「设置…」显示绿色小圆点和「设置…（有新版本 V1.11）」；
  进入设置窗口的「4．版本信息」，按钮变成绿色加粗的「绿点 + 立即更新 V1.11」
- 点这些入口都会用默认浏览器打开 GitHub 下载页，由你**手动下载更新**（程序不会自动下载或安装）
- 手动检查：托盘右键 →「设置…」→「4．版本信息」→ 点「检查更新」（托盘菜单已不再直接提供检查更新）
- 不想自动检查：设置 →「1．启动设置」→ 取消勾选「启动时自动检查更新」
- 暂时不想升级：设置 →「4．版本信息」→ 点击「跳过此版本 V1.11」；该版本不再提示，后续检测到更高版本时仍会重新显示更新提示
- 隐私：检查仅向 GitHub 请求最新版本号（不含任何本机信息、不上传任何数据），可随时关闭

【特点】
- 单个文件，约 83 KB，绿色免安装，拷到 U 盘也能用。
- 图标：透明背景 + 黑色剪刀轮廓，深色/浅色桌面与任务栏都清晰可见。
- 支持多显示器（区域/全屏截图均覆盖所有屏幕）。
- 高分屏(DPI)显示正常，像素不会偏移。
- 基于 Windows 自带 .NET Framework 4.x，Win10/Win11 均可直接运行，无需联网安装任何东西。
